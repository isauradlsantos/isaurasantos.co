How it works

Name the job. Set a clock. Leave.

  1. It asks before LinkedIn loads

    Pick an intent — message, post, research, inbox, notifications, or scroll & comment, then 5 to 25 minutes.

  2. Work with a live timer

    LinkedIn opens normally. The countdown runs on the Chrome badge and in the popup. Close the tab early and it logs how long you stayed.

  3. Time’s up, it locks

    A soft bell, then a lock screen. One quote if you want it. Then the tab closes.

Install

Load it unpacked. About a minute.

It isn’t on the Chrome Web Store yet. Download the folder, then load it as an unpacked extension.

  1. 1

    Download Sanity and unzip the folder.

  2. 2

    Open chrome://extensions/

  3. 3

    Turn on Developer mode

  4. 4

    Click Load unpacked and select the folder

  5. 5

    Pin Sanity in the toolbar, then open LinkedIn

FAQ

Quick answers

Is it free?

Yes. Sanity is a free Chrome extension, built by Isaura Santos.

Why isn’t it on the Chrome Web Store?

It isn’t listed yet. You install it unpacked in about a minute. Same flow in Arc, Brave, and Edge.

What happens when time is up?

A soft bell rings and LinkedIn locks. You can leave, start another session if budget remains, or take one quote on the way out.

Can I turn it off?

Yes. Pause Sanity for one hour from the popup if you really need to.
